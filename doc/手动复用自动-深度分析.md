# 手动模式复用自动模式 - 深度分析

> **核心理解：** 手动模式直接调用自动模式的逻辑，只是多了上传/下载音频的步骤

---

## 🎯 你的真实需求（终于懂了！）

**你说：** "我就问你现在我想用自动里的，然后手动也和自动的都一样"

**正确理解：**
```
自动模式流程：
1. 解析Word → TextSegment[]
2. 调用generateWithSingleTTS() → 生成音频
3. 返回音频

手动模式流程（你想要的）：
1. 用户上传音频文件 ← 唯一差异
2. 解析音频 → TextSegment[]
3. 调用generateWithSingleTTS() → 生成视频 ← 复用自动模式
4. 返回视频

核心：
- 手动模式不是"分段TTS"
- 手动模式是"用户提供音频"
- 处理逻辑完全复用自动模式
```

private AudioGenerationResult generateWithSingleTTS(...) {
    // 1. 合并所有文本

**关键发现：**
```
当前的"手动模式"其实是"分段TTS模式"
- 按speaker分段
- 多次调用TTS
- 复杂的合并和匹配逻辑

这不是你想要的"手动模式"！
```

**手动模式 ≠ 分段TTS**

```

关键：
- 场景B完全复用场景A的处理逻辑
- 唯一差异：音频来源（TTS生成 vs 用户上传）
```

### 方案：手动模式直接复用自动模式

**核心思路：**

### 代码结构调整

**Step 1：拆分generateWithSingleTTS()**

```java
// 原来的自动模式（包含TTS调用）
private AudioGenerationResult generateWithSingleTTS(...) {
    // 1. 合并文本
    String fullText = ...;
    
    // 2. 调用TTS生成音频
    byte[] fullAudio = ttsService.generateSpeechBytes(request);
    
    // 3. 处理音频（对齐、切分）
    return processAudio(segments, fullAudio, fullText, voiceConfig);
}

// 拆分后：TTS生成（自动模式专用）
private byte[] generateAudioByTTS(String fullText, String speaker, VoiceConfig config) {
    TTSRequest request = TTSRequest.builder()
            .text(fullText)
            .speaker(speaker)
            .format(config.getFormat())
            .sampleRate(config.getSampleRate())
            .build();
    
    return ttsService.generateSpeechBytes(request);
}

// 拆分后：音频处理（自动和手动共用）
private AudioGenerationResult processAudio(
        List<TextSegment> segments,
        byte[] fullAudio,
        String fullText,
        VoiceConfig voiceConfig,
        boolean skipAlignment) throws Exception {
    
    // 1. WhisperX对齐
    List<CharTimestamp> allChars = null;
    if (!skipAlignment && whisperXService.isAvailable()) {
        allChars = whisperXService.align(fullAudio, fullText);
    }
    
    // 2. 按paragraphId切分成DialogSegment
    List<DialogSegment> dialogSegments = splitIntoSentences(
            segments, allChars, fullAudio, voiceConfig);
    
    // 3. 计算总时长
    double totalDuration = calculateTotalDuration(fullAudio, voiceConfig);
    
    return new AudioGenerationResult(fullAudio, dialogSegments, totalDuration);
}
```

**Step 2：重构自动模式**

```java
/**
 * 自动模式：系统调用TTS生成音频
 */
private AudioGenerationResult generateWithSingleTTS(
        List<TextSegment> segments,
        VoiceConfig voiceConfig,
        boolean skipAlignment) throws Exception {
    
    log.info("[自动模式] 开始生成...");
    
    // 1. 合并所有文本
    String fullText = segments.stream()
            .map(TextSegment::getText)
            .collect(Collectors.joining());
    
    // 2. 调用TTS生成音频
    String speaker = segments.get(0).getSpeaker();
    byte[] fullAudio = generateAudioByTTS(fullText, speaker, voiceConfig);
    
    log.info("[自动模式] TTS完成，音频大小：{} KB", fullAudio.length / 1024.0);
    
    // 3. 处理音频（对齐、切分） ← 复用
    return processAudio(segments, fullAudio, fullText, voiceConfig, skipAlignment);
}
```

**Step 3：新增手动模式**

```java
/**
 * 手动模式：用户上传音频文件
 */
private AudioGenerationResult generateWithManualAudio(
        List<TextSegment> segments,
        byte[] userAudio,  // ← 用户上传的音频
        VoiceConfig voiceConfig,
        boolean skipAlignment) throws Exception {
    
    log.info("[手动模式] 使用用户音频...");
    log.info("[手动模式] 音频大小：{} KB", userAudio.length / 1024.0);
    
    // 1. 合并所有文本（和自动模式一样）
    String fullText = segments.stream()
            .map(TextSegment::getText)
            .collect(Collectors.joining());
    
    // 2. 直接使用用户音频（不调用TTS）
    byte[] fullAudio = userAudio;
    
    // 3. 处理音频（对齐、切分） ← 完全复用自动模式的逻辑！
    return processAudio(segments, fullAudio, fullText, voiceConfig, skipAlignment);
}
```
