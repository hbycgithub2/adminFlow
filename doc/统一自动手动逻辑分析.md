# 统一自动和手动模式逻辑分析

> **核心需求：** 手动模式改成和自动模式一样的逻辑，保持一致性  
> **目标：** 无论用自动还是手动，生成的视频效果一致

---

## 🎯 你的核心需求确认

**你说：** "自动的那个，手动的那个能改成自动的那个吗"

**理解：**
1. ✅ 自动模式的逻辑是对的（字幕准确、音质好）
2. ✅ 手动模式要改成和自动模式一样的逻辑
3. ✅ 两种模式保持一致，只是TTS调用方式不同

**关键点：**
- 自动模式：1次TTS调用（整句）
- 手动模式：N次TTS调用（分段）
- **两者的字幕生成逻辑应该一致**

## 🔍 当前两种模式的逻辑差异

### 自动模式的逻辑（splitIntoSentences）

```java
核心流程：
1. 合并所有文本为一段
   fullText = "小明：你好小红：你好"

2. 一次TTS生成整段音频
   byte[] fullAudio = TTS(fullText, speaker)

3. WhisperX整句对齐
   List<CharTimestamp> allChars = WhisperX.align(fullAudio, fullText)

4. 按paragraphId切分成DialogSegment
   遍历originalSegments，按paragraphId分组：
     段落1: "小明：你好小红：你好"
       - 从allChars中提取字符0-7的时间戳
       - 创建DialogSegment1
     
     段落2: "小明：再见"
       - 从allChars中提取字符8-11的时间戳
       - 创建DialogSegment2

特点：
✅ 字符索引连续递增（charIndex++）
✅ 音频连续，时间戳连续
✅ 一一对应，完美同步
```

### 手动模式的逻辑（buildDialogSegments）

```java
核心流程：
1. 按speaker合并成MergedSegment
   MergedSegment1: "小明：你好" (BV700)
   MergedSegment2: "小红：你好" (BV123)
   MergedSegment3: "小明：再见" (BV700)

2. 多次TTS生成音频
   AudioSegment1: TTS("小明：你好", BV700)
   AudioSegment2: TTS("小红：你好", BV123)
   AudioSegment3: TTS("小明：再见", BV700)

3. WhisperX批量对齐
   batchResults[0]: [小, 明, :, 你, 好]
   batchResults[1]: [小, 红, :, 你, 好]
   batchResults[2]: [小, 明, :, 再, 见]

4. 按paragraphId合并成Line，然后按speaker匹配AudioSegment
   Line1: "小明：你好小红：你好" (paragraphId=1)
     → 尝试匹配AudioSegment（按speaker）
     → AudioSegment1 (BV700) ✅
     → AudioSegment2 (BV123) ❌ speaker不同，停止匹配
     → ❌ 只匹配到AudioSegment1，"小红：你好"丢失

特点：
❌ 按speaker合并，按paragraphId分组，逻辑不一致
❌ 映射断裂，字幕不准
```

## 💡 核心问题分析

### 问题：为什么两种模式逻辑不一致？

**自动模式：**
```
合并逻辑: 按paragraphId
切分逻辑: 按paragraphId
匹配逻辑: 字符索引连续递增

结果：完美一致 ✅
```

**手动模式：**
```
合并逻辑: 按speaker  ← ❌ 和自动模式不同
切分逻辑: 按paragraphId
匹配逻辑: 按speaker ← ❌ 和切分逻辑不一致

结果：映射断裂 ❌
```

### 根本原因

**手动模式的双重标准：**
1. 第1步（TTS生成）：按`speaker`合并
2. 第2步（DialogSegment构建）：按`paragraphId`分组
3. 第3步（AudioSegment匹配）：按`speaker`匹配

**当段落内有多个speaker时：**
- 第2步生成的Line包含多个speaker的文本
- 第3步只能匹配到第一个speaker的AudioSegment
- 其他speaker的AudioSegment丢失 → 字幕不准

---

## 🎯 解决方案：统一为自动模式的逻辑

### 核心思路：让手动模式完全模仿自动模式

**自动模式的核心逻辑：**
```
1. 按paragraphId分组
2. 每个段落对应一个"语音片段"
3. 字符时间戳按顺序提取
4. 一一对应
```

**手动模式应该改为：**
```
1. 按paragraphId分组（而不是按speaker）
2. 每个段落生成一个AudioSegment
3. DialogSegment和AudioSegment按索引一一对应
4. 完全模仿自动模式的逻辑
```

## 📋 详细改造方案

### 改造点1：TTS生成改为按paragraphId合并

**当前逻辑（按speaker合并）：**
```java
// TextSegmentMerger.merge()
List<MergedSegment> merge(List<TextSegment> segments) {
    for (TextSegment segment : segments) {
        if (segment.getSpeaker().equals(currentSpeaker)) {
            // 相同speaker，合并
            currentMergedSegment.append(segment.getText());
        } else {
            // speaker不同，输出当前，开始新的
            result.add(currentMergedSegment);
            currentSpeaker = segment.getSpeaker();
            currentMergedSegment = new MergedSegment(segment);
        }
    }
}

结果：
  MergedSegment1: "小明：你好" (speaker=BV700)
  MergedSegment2: "小红：你好" (speaker=BV123)
  MergedSegment3: "小明：再见" (speaker=BV700)
```

**改造后逻辑（按paragraphId合并）：**
```java
// TextSegmentMerger.mergeByParagraph()
List<MergedSegment> mergeByParagraph(List<TextSegment> segments) {
    for (TextSegment segment : segments) {
        if (segment.getParagraphId().equals(currentParagraphId)) {
            // 相同段落，合并
            currentMergedSegment.append(segment.getText());
            // 注意：保留第一个segment的speaker
        } else {
            // 段落不同，输出当前，开始新的
            result.add(currentMergedSegment);
            currentParagraphId = segment.getParagraphId();
            currentMergedSegment = new MergedSegment(segment);
        }
    }
}

结果：
  MergedSegment1: "小明：你好小红：你好" (speaker=BV700, paragraphId=1)
  MergedSegment2: "小明：再见" (speaker=BV700, paragraphId=2)
```

### 改造点2：DialogSegment构建改为按索引一一对应

**当前逻辑（复杂的speaker匹配）：**
```java
// buildDialogSegments() - 当前
for (int lineIndex = 0; lineIndex < lines.size(); lineIndex++) {
    LineInfo line = lines.get(lineIndex);
    
    // 复杂的speaker匹配逻辑
    List<AudioSegment> lineAudioSegments = new ArrayList<>();
    while (audioIndex < audioSegments.size()) {
        AudioSegment audio = audioSegments.get(audioIndex);
        
        // 判断speaker是否匹配
        if (!audio.getMergedSegment().getSpeaker().equals(line.speaker)) {
            break;  // speaker不同，停止匹配
        }
        
        lineAudioSegments.add(audio);
        audioIndex++;
    }
    
    // 从批量结果中提取对齐信息
    // ... 复杂的映射逻辑
}
```

**改造后逻辑（简单的索引对应）：**
```java
// buildDialogSegmentsSimple() - 模仿自动模式
List<DialogSegment> dialogSegments = new ArrayList<>();
double currentTime = 0.0;

// ✅ 关键：直接按索引一一对应（模仿自动模式）
for (int i = 0; i < mergedSegments.size(); i++) {
    MergedSegment merged = mergedSegments.get(i);
    AudioSegment audio = audioSegments.get(i);  // ← 按索引对应
    List<CharTimestamp> whisperXChars = batchResults.get(i);  // ← 按索引对应
    
    // 转换WhisperX结果（完全模仿splitIntoSentences）
    List<CharTiming> charTimings = new ArrayList<>();
    for (CharTimestamp wchar : whisperXChars) {
        CharTiming ct = new CharTiming();
        ct.setCharacter(wchar.getCharacter());
        ct.setStartTime(currentTime + wchar.getStartTime());
        ct.setDuration(wchar.getDuration());
        charTimings.add(ct);
    }
    
    // 计算时长
    double duration = whisperXChars.get(whisperXChars.size() - 1).getEndTime();
    
    // 创建DialogSegment（完全模仿splitIntoSentences）
    DialogSegment dialog = DialogSegment.builder()
            .index(i)
            .text(merged.getText())
            .voiceId(merged.getSpeaker())
            .startTime(currentTime)
            .duration(duration)
            .charTimings(charTimings)
            .build();
    
    dialogSegments.add(dialog);
    
    // 累加时间（音频时长 + 停顿）
    currentTime += duration;
    if (audio.getNeedPause()) {
        currentTime += audio.getPauseDuration() / 1000.0;
    }
}

return dialogSegments;
```
