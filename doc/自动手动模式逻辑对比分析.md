# 自动模式 vs 手动模式逻辑对比分析

> **分析时间：** 2026-08-17  
> **问题描述：** 自动模式和手动模式在语音和文字同步上表现不一致  
> **核心目标：** 分析两种模式的逻辑差异，找出不同步的根本原因

---

## 📊 核心对比总结

| 维度 | 自动模式（整句TTS） | 手动模式（分段TTS） | 是否一致 |
|------|-------------------|-------------------|---------|
| **TTS调用** | 1次调用（整段文本） | 多次调用（按音色分段） | ❌ 不同 |
| **文本切分** | 按`paragraphId`切分 | 按`speaker`切分 | ❌ 不同 |
| **对齐方式** | WhisperX整句对齐 | WhisperX批量对齐 | ⚠️ 类似但实现不同 |
| **DialogSegment生成** | `splitIntoSentences()` | `buildDialogSegments()` | ❌ 完全不同 |
| **结果一致性** | ✅ 音频-字幕同步正常 | ❌ 音频-字幕不同步 | ❌ 不同 |

---

## 🔍 详细逻辑对比

### 1️⃣ 自动模式（整句TTS）- `generateWithSingleTTS()`

#### 工作流程
```
1. 合并所有文本为一段完整文本
   └─ fullText = segments.stream().map(TextSegment::getText).join()
   └─ speaker = segments.get(0).getSpeaker()  // 使用第一个speaker

2. 调用TTS API（1次）
   └─ byte[] fullAudio = ttsService.generateSpeechBytes(fullText, speaker)

3. WhisperX对齐（1次）
   └─ List<CharTimestamp> allChars = whisperXService.align(fullAudio, fullText)

4. 按段落切分生成DialogSegment
   └─ splitIntoSentences(segments, allChars, fullAudio, voiceConfig)
```

#### 关键逻辑：`splitIntoSentences()`

```java
// ✅ 按paragraphId分组
Map<Integer, List<TextSegment>> paragraphMap = new LinkedHashMap<>();
for (TextSegment segment : originalSegments) {
    paragraphMap.computeIfAbsent(segment.getParagraphId(), k -> new ArrayList<>()).add(segment);
}

// 遍历每个段落
for (Map.Entry<Integer, List<TextSegment>> entry : paragraphMap.entrySet()) {
    Integer paragraphId = entry.getKey();
    List<TextSegment> paragraphSegments = entry.getValue();
    
    // 合并段落文本
    String paragraphText = paragraphSegments.stream()
            .map(TextSegment::getText)
            .collect(Collectors.joining());
    
    // 收集这个段落的所有字符时间戳
    List<CharTiming> charTimings = new ArrayList<>();
    for (int i = 0; i < paragraphText.length() && charIndex < allChars.size(); i++, charIndex++) {
        CharTimestamp whisperXChar = allChars.get(charIndex);
        charTimings.add(convert(whisperXChar));
    }
    
    // 创建DialogSegment（一个段落 = 一个DialogSegment）
    DialogSegment dialogSegment = new DialogSegment();
    dialogSegment.setText(paragraphText);
    dialogSegment.setVoiceId(speaker);
    dialogSegment.setCharTimings(charTimings);
    dialogSegments.add(dialogSegment);
}
```

**核心特点：**
- ✅ 按`paragraphId`分组，每个段落对应一个DialogSegment
- ✅ 字符时间戳按顺序从`allChars`中提取，保持一一对应
- ✅ 音频是连续的，字符索引也是连续递增的

### 2️⃣ 手动模式（分段TTS）- `generateWithMultiTTS()`

#### 工作流程
```
1. 按speaker合并相同音色的连续片段
   └─ List<MergedSegment> mergedSegments = segmentMerger.merge(segments)
   └─ 合并策略：相同speaker的segment合并

2. 并发调用TTS API（多次）
   └─ List<AudioSegment> audioSegments = synthesizeParallel(mergedSegments, voiceConfig)
   └─ 每个MergedSegment对应一个AudioSegment

3. WhisperX批量对齐（多次）
   └─ List<List<CharTimestamp>> batchResults = whisperXService.alignBatch(allAudios, allTexts)
   └─ 每个AudioSegment单独对齐

4. 按"行"合并生成DialogSegment
   └─ buildDialogSegments(segments, audioSegments, voiceConfig, skipAlignment)
```

#### 关键逻辑：`buildDialogSegments()`

```java
// ❌ 第一步：按paragraphId合并成"行"
List<LineInfo> lines = new ArrayList<>();
Integer currentParagraphId = originalSegments.get(0).getParagraphId();
String currentSpeaker = originalSegments.get(0).getSpeaker();

for (TextSegment segment : originalSegments) {
    boolean shouldOutput = !segment.getParagraphId().equals(currentParagraphId);
    
    if (shouldOutput) {
        lines.add(new LineInfo(lineText, currentBold, currentSpeaker));
        currentParagraphId = segment.getParagraphId();
        currentSpeaker = segment.getSpeaker();
        lineText = new StringBuilder();
    }
    
    lineText.append(segment.getText());
}

// ❌ 第二步：匹配AudioSegment到"行"
for (int lineIndex = 0; lineIndex < lines.size(); lineIndex++) {
    LineInfo line = lines.get(lineIndex);
    
    // 找到对应的AudioSegment（按speaker匹配）
    List<AudioSegment> lineAudioSegments = new ArrayList<>();
    while (audioIndex < audioSegments.size()) {
        AudioSegment audioSegment = audioSegments.get(audioIndex);
        String nextSpeaker = audioSegment.getMergedSegment().getSpeaker();
        
        // ❌ 关键判断：当speaker不同时停止
        if (!nextSpeaker.equals(line.speaker)) {
            break;
        }
        
        lineAudioSegments.add(audioSegment);
        audioIndex++;
    }
    
    // 从批量结果中提取对齐信息
    for (AudioSegment audioSegment : lineAudioSegments) {
        Integer batchIdx = segmentToBatchIndexMap.get(lineIndex + "-" + segIdx);
        List<CharTimestamp> whisperXChars = batchResults.get(batchIdx);
        charTimings.addAll(whisperXChars);
    }
    
    // 创建DialogSegment
    dialogSegments.add(dialogSegment);
}
```

**核心特点：**
- ❌ 第一步按`paragraphId`合并成"行"
- ❌ 第二步按`speaker`匹配AudioSegment
- ❌ 如果一个段落有多个speaker，会出现错位
- ❌ 字符时间戳和音频的映射关系可能断裂

## 🐛 根本问题分析

### 问题1：合并逻辑不一致

**自动模式：**
```
TextSegment按paragraphId分组
  ↓
每个段落合并为一段文本
  ↓
整句TTS生成音频
  ↓
WhisperX整句对齐
  ↓
按paragraphId切分DialogSegment
  ↓
✅ 一一对应，完美同步
```

**手动模式：**
```
TextSegment按speaker合并
  ↓
每个speaker合并为一个MergedSegment
  ↓
多次TTS生成音频（按speaker）
  ↓
WhisperX批量对齐（按speaker）
  ↓
按paragraphId合并成"行"（Line）
  ↓
按speaker匹配AudioSegment到Line
  ↓
❌ 映射错位，音频-字幕不同步
```

### 问题2：映射断裂场景

假设文档结构如下：
```
段落1（paragraphId=1）:
  - Segment1: "你好" (speaker=BV700_streaming)
  - Segment2: "世界" (speaker=BV123_streaming)

段落2（paragraphId=2）:
  - Segment3: "我是" (speaker=BV700_streaming)
  - Segment4: "Kiro" (speaker=BV123_streaming)
```

**自动模式处理：**
```
合并文本：
  段落1: "你好世界"
  段落2: "我是Kiro"

TTS调用（1次）：
  fullText = "你好世界我是Kiro"
  speaker = BV700_streaming

WhisperX对齐（1次）：
  allChars = [你, 好, 世, 界, 我, 是, K, i, r, o]

生成DialogSegment：
  DialogSegment1: "你好世界" (段落1)
  DialogSegment2: "我是Kiro" (段落2)
  
✅ 结果：音频连续，字符时间戳连续，完美同步
```

**手动模式处理：**
```
按speaker合并：
  MergedSegment1: "你好" (BV700)
  MergedSegment2: "世界" (BV123)
  MergedSegment3: "我是" (BV700)
  MergedSegment4: "Kiro" (BV123)

TTS调用（4次）：
  AudioSegment1: "你好" (BV700)
  AudioSegment2: "世界" (BV123)
  AudioSegment3: "我是" (BV700)
  AudioSegment4: "Kiro" (BV123)

WhisperX批量对齐（4次）：
  batchResults[0]: [你, 好]
  batchResults[1]: [世, 界]
  batchResults[2]: [我, 是]
  batchResults[3]: [K, i, r, o]

按paragraphId合并成Line：
  Line1: "你好世界" (paragraphId=1, speaker=BV700)  ← ❌ 注意：speaker取第一个segment
  Line2: "我是Kiro" (paragraphId=2, speaker=BV700)  ← ❌ 注意：speaker取第一个segment

按speaker匹配AudioSegment：
  Line1匹配：
    - AudioSegment1: "你好" (BV700) ✅
    - AudioSegment2: "世界" (BV123) ❌ speaker不同，停止匹配
    - 结果：Line1只匹配到AudioSegment1
    - ❌ 问题："世界"的音频丢失！

  Line2匹配：
    - AudioSegment2: "世界" (BV123) ❌ speaker不同，跳过
    - AudioSegment3: "我是" (BV700) ✅
    - AudioSegment4: "Kiro" (BV123) ❌ speaker不同，停止匹配
    - 结果：Line2只匹配到AudioSegment3
    - ❌ 问题："Kiro"的音频丢失！

生成DialogSegment：
  DialogSegment1: "你好世界"
    - charTimings: [你, 好]  ← ❌ 只有"你好"，缺少"世界"
  DialogSegment2: "我是Kiro"
    - charTimings: [我, 是]  ← ❌ 只有"我是"，缺少"Kiro"

❌ 结果：字幕显示"你好世界"，但音频只有"你好"，不同步！
```

## 💡 解决方案分析

### 方案A：手动模式改用paragraphId合并（推荐）⭐⭐⭐⭐⭐

**核心思路：** 让手动模式的合并逻辑和自动模式一致

**修改点1：`segmentMerger.merge()` 改为按paragraphId合并**
```java
// 当前（按speaker合并）：
List<MergedSegment> merge(List<TextSegment> segments) {
    // 相同speaker的segment合并
    if (segment.getSpeaker().equals(currentSpeaker)) {
        merge();
    }
}

// 修改后（按paragraphId合并）：
List<MergedSegment> merge(List<TextSegment> segments) {
    // 相同paragraphId的segment合并（保留speaker信息）
    if (segment.getParagraphId().equals(currentParagraphId)) {
        merge();
    }
}
```

**修改点2：`buildDialogSegments()` 匹配逻辑改为按paragraphId**
```java
// 当前（按speaker匹配）：
if (!nextSpeaker.equals(line.speaker)) {
    break;  // speaker不同，停止匹配
}

// 修改后（按paragraphId匹配）：
if (!nextSegment.getParagraphId().equals(currentParagraphId)) {
    break;  // paragraphId不同，停止匹配
}
```

**优点：**
- ✅ 统一逻辑，自动和手动模式完全一致
- ✅ 彻底解决映射断裂问题
- ✅ 代码更简洁，更易维护

**缺点：**
- ⚠️ 如果一个段落有多个speaker，会丢失音色差异（但字幕会正确显示）
- ⚠️ 需要修改`TextSegmentMerger`的合并逻辑

**结果预测：**
```
段落1（paragraphId=1）:
  MergedSegment1: "你好世界" (包含两个speaker的文本)
  
段落2（paragraphId=2）:
  MergedSegment2: "我是Kiro" (包含两个speaker的文本)

TTS调用（2次）:
  AudioSegment1: "你好世界" (使用第一个speaker)
  AudioSegment2: "我是Kiro" (使用第一个speaker)

WhisperX批量对齐（2次）:
  batchResults[0]: [你, 好, 世, 界]
  batchResults[1]: [我, 是, K, i, r, o]

生成DialogSegment:
  DialogSegment1: "你好世界"
    - charTimings: [你, 好, 世, 界] ✅ 完整
  DialogSegment2: "我是Kiro"
    - charTimings: [我, 是, K, i, r, o] ✅ 完整

✅ 结果：音频-字幕完美同步
```

## 🎯 推荐方案

### ✅ 推荐：方案A（统一按paragraphId合并）

**理由：**
1. **逻辑统一：** 自动和手动模式使用相同的合并逻辑
2. **根本解决：** 彻底解决映射断裂问题
3. **易于维护：** 代码更简洁，逻辑更清晰
4. **用户体验：** 字幕按段落显示，符合阅读习惯

**注意事项：**
- 如果段落内有多个speaker，音色会统一为第一个speaker
- 这是合理的权衡：字幕正确性 > 音色差异
- 如果用户需要精确的多音色支持，应该在Word文档中分段落编写

**实现步骤：**
1. 修改`TextSegmentMerger.merge()`：按paragraphId合并，而不是按speaker
2. 修改`buildDialogSegments()`：匹配AudioSegment时按paragraphId，而不是按speaker
3. 保持`splitIntoSentences()`不变（已经是按paragraphId）
4. 测试：确保自动和手动模式都按paragraphId工作
