## 💡 手动模式如何完全模仿自动模式

```
整个文档 → 用第一个speaker → 生成整段音频
```

**手动模式要模仿：**
```
每个段落 → 用该段落第一个speaker → 生成该段落音频
```

## 🎯 核心策略

### 策略：段落级音色统一

**原则：**
```
1. 每个段落用该段落第一个segment的speaker
2. 段落内所有文本用同一个音色
3. 完全模仿自动模式的音色处理方式
```

**实现逻辑：**
```java
// 按paragraphId分组
Map<Integer, List<TextSegment>> paragraphMap = segments.stream()
        .collect(Collectors.groupingBy(TextSegment::getParagraphId));

// 为每个段落生成MergedSegment
for (Map.Entry<Integer, List<TextSegment>> entry : paragraphMap.entrySet()) {
    List<TextSegment> paragraphSegments = entry.getValue();
    
    // 合并段落文本
    String text = paragraphSegments.stream()
            .map(TextSegment::getText)
            .collect(Collectors.joining());
    
    // ✅ 关键：使用段落第一个segment的speaker（模仿自动模式）
    String speaker = paragraphSegments.get(0).getSpeaker();
    
    MergedSegment merged = new MergedSegment();
    merged.setText(text);
    merged.setSpeaker(speaker);  // ← 段落内统一音色
    merged.setParagraphId(entry.getKey());
    
    result.add(merged);
}
```

## 🤔 核心问题：能否做到完全一致？

### 问题：自动vs手动的根本差异

**自动模式的本质：**
```
1次TTS调用 → 整段文本 → 用1个音色 → 生成连续音频
```

**手动模式的本质：**
```
N次TTS调用 → N个片段 → 用N个音色 → 拼接成完整音频
```

**根本矛盾：**
```
如果手动模式要和自动模式的音色处理完全一样：
  → 手动模式也要整个文档用1个音色
  → 那就失去了手动模式的意义（支持多音色）
  → 不如直接用自动模式

如果手动模式要支持多音色：
  → 必然和自动模式的音色处理不一样
  → 自动模式是全文统一音色
  → 手动模式至少是段落级音色
```

```java
/**
 * 按paragraphId合并（模仿自动模式的逻辑）
 */
public List<MergedSegment> mergeByParagraph(List<TextSegment> segments) {
    Map<Integer, List<TextSegment>> paragraphMap = segments.stream()
            .collect(Collectors.groupingBy(TextSegment::getParagraphId));
    
    List<MergedSegment> result = new ArrayList<>();
    
    for (Map.Entry<Integer, List<TextSegment>> entry : paragraphMap.entrySet()) {
        List<TextSegment> paragraphSegments = entry.getValue();
        
        // 合并段落文本
        String text = paragraphSegments.stream()
                .map(TextSegment::getText)
                .collect(Collectors.joining());
        
        // ✅ 使用段落第一个segment的speaker（段落内统一音色）
        String speaker = paragraphSegments.get(0).getSpeaker();
        
        MergedSegment merged = new MergedSegment();
        merged.setText(text);
        merged.setSpeaker(speaker);
        merged.setParagraphId(entry.getKey());
        
        result.add(merged);
    }
    
    return result;
}
```

```java
private AudioGenerationResult generateWithMultiTTS(...) {
    // 1. 按paragraphId合并（模仿自动模式）
    List<MergedSegment> mergedSegments = segmentMerger.mergeByParagraph(segments);

/**
 * 简化版DialogSegment构建（完全模仿splitIntoSentences）
 */
private List<DialogSegment> buildDialogSegmentsSimple(...) {
    List<DialogSegment> dialogSegments = new ArrayList<>();
    double currentTime = 0.0;
    
    // ✅ 按索引一一对应（模仿自动模式的字符索引递增逻辑）
    for (int i = 0; i < mergedSegments.size(); i++) {
        MergedSegment merged = mergedSegments.get(i);
        AudioSegment audio = audioSegments.get(i);
        List<CharTimestamp> whisperXChars = batchResults.get(i);
        
        // 转换时间戳（模仿splitIntoSentences）
        List<CharTiming> charTimings = convertWhisperXToCharTimings(
                whisperXChars, currentTime);
        
        // 计算时长
        double duration = whisperXChars.get(whisperXChars.size() - 1).getEndTime();
        
        // 创建DialogSegment（完全模仿splitIntoSentences）
        DialogSegment dialog = DialogSegment.builder()
                .index(i)
                .text(merged.getText())
                .voiceId(merged.getSpeaker())  // ← 段落第一个speaker
                .startTime(currentTime)
                .duration(duration)
                .charTimings(charTimings)
                .build();
        
        dialogSegments.add(dialog);
        currentTime += duration + pauseDuration;
    }
    
    return dialogSegments;
}
```
