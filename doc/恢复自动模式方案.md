# 恢复自动模式方案

> **目标：** 把自动模式恢复到原来正确的版本  
> **问题：** commit 89ef545引入了新逻辑，但手动模式有bug

---

## 🔍 问题分析

### Commit 89ef545做了什么？

**新增内容（✅ 好的）：**
1. ✅ 新增 `generateWithSingleTTS()` - 自动模式（整句TTS）
2. ✅ 新增 `splitIntoSentences()` - 按paragraphId切分
3. ✅ 新增 `checkCanUseSingleTTS()` - 智能判断
4. ✅ 新增 `paragraphId` 字段支持

**修改内容（❌ 有问题）：**
1. ❌ 修改 `buildDialogSegments()` - 从按isBold改为按paragraphId
2. ❌ 这个修改导致手动模式出现字幕不同步的bug

**保留（不动）：**
- ✅ `generateWithSingleTTS()` - 自动模式（工作正常）

**恢复（回退）：**
- ❌ `buildDialogSegments()` - 恢复到commit abb1c23的版本（按isBold合并）
- ❌ 或者直接让手动模式调用自动模式的逻辑

### 方案2：手动模式直接复用自动模式（推荐）⭐⭐⭐⭐⭐

**思路：**
```
不恢复 buildDialogSegments()
而是让 generateWithMultiTTS() 改为调用自动模式的逻辑
```

**核心改动：**
```java
// 当前的 generateWithMultiTTS()
private AudioGenerationResult generateWithMultiTTS(...) {
    // 1. 按speaker合并
    List<MergedSegment> mergedSegments = segmentMerger.merge(segments);
    
    // 2. 多次TTS
    List<AudioSegment> audioSegments = synthesizeParallel(mergedSegments, voiceConfig);
    
    // 3. ❌ 调用 buildDialogSegments()（有bug）
    List<DialogSegment> dialogSegments = buildDialogSegments(segments, audioSegments, voiceConfig, skipAlignment);
    
    // 4. 合并音频
    byte[] finalAudio = audioMerger.merge(audioSegments, sampleRate);
}

// 改为（复用自动模式）：
private AudioGenerationResult generateWithMultiTTS(...) {
    // 1. 合并所有文本（和自动模式一样）
    String fullText = segments.stream()
            .map(TextSegment::getText)
            .collect(Collectors.joining());
    
    // 2. 按paragraphId合并生成音频
    List<MergedSegment> mergedByParagraph = mergeByParagraph(segments);
    List<AudioSegment> audioSegments = synthesizeParallel(mergedByParagraph, voiceConfig);
    
    // 3. 合并音频
    byte[] finalAudio = audioMerger.merge(audioSegments, sampleRate);
    
    // 4. ✅ 调用自动模式的逻辑！
    List<CharTimestamp> allChars = null;
    if (!skipAlignment && whisperXService.isAvailable()) {
        allChars = whisperXService.align(finalAudio, fullText);
    }
    
    // 5. ✅ 使用 splitIntoSentences()（和自动模式一样）
    List<DialogSegment> dialogSegments = splitIntoSentences(
            segments, allChars, finalAudio, voiceConfig);
    
    return new AudioGenerationResult(finalAudio, dialogSegments, totalDuration);
}
```

**优点：**
- ✅ 自动和手动模式逻辑完全一致
- ✅ 字幕100%准确
- ✅ 不需要恢复旧代码
- ✅ 代码更简洁

**缺点：**
- ⚠️ 需要新增 mergeByParagraph() 方法
