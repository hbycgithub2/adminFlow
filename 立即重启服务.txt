步骤1：停止当前服务
--------------------
在运行服务的窗口按：Ctrl + C

步骤2：重新启动服务
--------------------
使用以下任意一种方法：

方法A（Maven）：
cd d:\code\adminFlow\hm-service
mvn spring-boot:run

方法B（IDE - 最简单）：
1. 在IDEA中找到 HmServiceApplication.java
2. 右键 → Run

方法C（jar包）：
cd d:\code\adminFlow\hm-service
java -jar target\hm-service-1.0.0.jar

步骤3：等待启动完成
--------------------
看到以下日志说明成功：
