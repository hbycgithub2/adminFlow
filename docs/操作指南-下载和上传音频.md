## 📋 操作步骤详解

### 步骤1：生成音频 🎵

```
┌──────────────────────────────────┐
│  步骤1：生成音频                  │
│                                  │
│  ┌──────────────────────────┐  │
│  │ 📄 点击选择Word文档       │  │
│  └──────────────────────────┘  │
│                                  │
│  [🎵 生成音频]                   │
└──────────────────────────────────┘
```

**操作**:
1. 点击"📄 点击选择Word文档"区域
2. 选择你的Word文档（.docx格式）
3. 点击"🎵 生成音频"按钮
4. 等待生成（约6-10秒）

**结果**:
```
┌──────────────────────────────────┐
│  ✅ 音频生成成功！                │
│                                  │
│  音频: [🎵 下载MP3] ⭐            │
│  时长: 120.5秒                   │
│                                  │
│  💡 提示：下载MP3后，您可以使用   │
│  音频编辑软件（如Audacity）进行   │
│  编辑                            │
│                                  │
│  [➡️ 下一步：上传编辑后的音频]   │
└──────────────────────────────────┘
```

**重点**:
- 点击 **"🎵 下载MP3"** 按钮下载音频文件 ⭐
- 此时可以用音频编辑软件编辑MP3（调整语速、添加背景音乐等）

---

### 步骤2：上传音频生成视频 🎬

**操作**:
1. 点击"➡️ 下一步：上传编辑后的音频"按钮
2. 页面会跳转到步骤2

```
┌──────────────────────────────────┐
│  步骤2：上传编辑后的音频          │
│                                  │
│  ┌──────────────────────────┐  │
│  │ 🎵 点击选择音频文件       │  │
│  │ 支持MP3、WAV格式          │  │
│  └──────────────────────────┘  │
│                                  │
│  [🎬 生成视频]                   │
└──────────────────────────────────┘
```

**操作**:
1. 点击"🎵 点击选择音频文件"区域
2. 选择编辑后的MP3文件（或原始MP3）⭐
3. 点击"🎬 生成视频"按钮
4. 等待生成（约10-20秒）

**结果**:
```
┌──────────────────────────────────┐
│  ✅ 视频生成成功！                │
│                                  │
│  视频: [📹 查看视频]             │
│  重新对齐: 是                    │
└──────────────────────────────────┘
```
