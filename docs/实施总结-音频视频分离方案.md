## 🔧 核心技术实现

### 1. AudioGeneratorService

**职责**: 专门负责音频生成，与视频解耦

**核心逻辑**:
```java
public AudioGenerateResponse generateAudioFromDocument(MultipartFile file, VoiceConfig voiceConfig) {
    // 调用DocumentTTSService生成音频和字幕
    DocumentTTSResult ttsResult = documentTTSService.generateDocumentSpeech(file, voiceConfig);
    
    // 返回音频URL、字幕数据、时长等信息
    return AudioGenerateResponse.success(...);
}
```

**特点**:
- 复用现有DocumentTTSService
- 返回完整的字幕数据（DialogSegments）
- 支持后续编辑和重用

---

### 2. SubtitleAlignmentService

**职责**: 智能处理字幕对齐

**核心策略**（三层降级）:
```java
1. 有原始字幕 + MP3未变化 → 直接使用原始字幕 (100%准确)
2. 有原始字幕 + MP3变化 → WhisperX重新对齐 (98%准确)
3. 有原始文本 → WhisperX对齐 (98%准确)
4. 兜底 → Whisper识别 (90%准确)
```

**核心逻辑**:
```java
public List<DialogSegment> alignSubtitles(
        byte[] audioData,
        List<DialogSegment> originalSubtitles,
        String originalText,
        boolean forceReAlign) {
    
    // 检测音频是否变化
    if (!forceReAlign && !isAudioModified(audioData, originalSubtitles)) {
        return originalSubtitles; // 策略1：直接使用
    }
    
    // 策略2、3：WhisperX对齐
    if (originalText != null) {
        return reAlignWithWhisperX(audioData, originalText, originalSubtitles);
    }
    
    // 策略4：兜底
    return recognizeOnly(audioData);
}
```

**检测逻辑**:
- 通过比较音频时长判断是否编辑
- 如果时长差异 > 1秒，判定为已编辑

### 3. VideoGeneratorService增强

**新增方法**: `generateVideoFromAudio`

**核心流程**:
```java
public VideoGenerateResponse generateVideoFromAudio(
        MultipartFile audioFile, 
        VideoFromAudioRequest request) {
    
    // 1. 保存音频文件
    Path audioPath = saveAudioFile(audioFile, fileName);
    
    // 2. 智能对齐字幕
    List<DialogSegment> dialogSegments = subtitleAlignmentService.alignSubtitles(
        audioData, 
        request.getSubtitles(), 
        request.getOriginalText(),
        request.getForceReAlign()
    );
    
    // 3. 生成ASS字幕
    String assContent = assSubtitleGenerator.generateASS(...);
    
    // 4. FFmpeg生成视频
    ffmpegUtil.generateVideo(audioPath, assPath, videoPath, videoConfig);
    
    // 5. 返回结果
    return VideoGenerateResponse.builder()
        .videoUrl(...)
        .reAligned(...)  // 标识是否重新对齐
        .build();
}
```

## 🎨 前端集成示例

### 三种使用模式

#### 模式1：快速模式
```javascript
// 一键生成视频
const formData = new FormData();
formData.append('file', wordFile);

const response = await fetch('/api/video-generator/generate', {
    method: 'POST',
    body: formData
});

const result = await response.json();
console.log('视频URL:', result.videoUrl);
console.log('音频URL:', result.audioUrl); // ⭐ 可以下载
```

#### 模式2：灵活模式
```javascript
// 步骤1：生成音频
const audioResponse = await fetch('/api/audio/generate', {
    method: 'POST',
    body: formData
});

const audioResult = await audioResponse.json();
localStorage.setItem('subtitles', JSON.stringify(audioResult.subtitles));

// 步骤2：上传编辑后的MP3生成视频
const videoFormData = new FormData();
videoFormData.append('audio', editedAudioFile);
videoFormData.append('subtitles', localStorage.getItem('subtitles'));
videoFormData.append('forceReAlign', 'true');

const videoResponse = await fetch('/api/video-generator/generate-from-audio', {
    method: 'POST',
    body: videoFormData
});
```

#### 模式3：自定义模式
```javascript
// 上传自己的MP3 + 原始文本
const formData = new FormData();
formData.append('audio', myAudioFile);
formData.append('originalText', '这是我的录音内容...');
formData.append('forceReAlign', 'true');

const response = await fetch('/api/video-generator/generate-from-audio', {
    method: 'POST',
    body: formData
});
```
