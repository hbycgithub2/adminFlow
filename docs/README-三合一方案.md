## 🎯 方案概述

### 核心理念

**三合一混合方案** = 一键生成 + 灵活编辑 + 自定义音频

支持三种使用模式，满足不同场景需求：

```
模式1：快速模式 ⚡
  上传Word → 一键生成 → 返回视频+音频
  
模式2：灵活模式 🎨
  上传Word → 生成音频 → 下载编辑 → 上传生成视频
  
模式3：自定义模式 🎵
  上传MP3 → 提供文本 → 生成视频
```

---

## 🚀 快速开始

### 1. 一键生成视频（最简单）

```bash
curl -X POST http://localhost:8080/api/video-generator/generate \
  -F "file=@document.docx" \
  -F "boldVoice=zh_male_m191_uranus_bigtts" \
  -F "normalVoice=zh_female_vv_uranus_bigtts"
```

**响应**:
```json
{
  "success": true,
  "videoUrl": "/tts/videos/abc123.mp4",
  "audioUrl": "/tts/documents/abc123.mp3",  // ⭐ 可下载
  "duration": 120.5,
  "subtitles": [...]
}
```

---

### 2. 分步生成（灵活模式）

**步骤1: 生成音频**
```bash
curl -X POST http://localhost:8080/api/audio/generate \
  -F "file=@document.docx"
```

**步骤2: 下载MP3并编辑**（可选）
- 调整语速
- 添加背景音乐
- 裁剪片段

**步骤3: 上传生成视频**
```bash
curl -X POST http://localhost:8080/api/video-generator/generate-from-audio \
  -F "audio=@edited_audio.mp3" \
  -F "subtitles=${subtitles_json}" \
  -F "forceReAlign=true"
```

---

### 3. 使用自己的音频

```bash
curl -X POST http://localhost:8080/api/video-generator/generate-from-audio \
  -F "audio=@my_recording.mp3" \
  -F "originalText=这是我的录音内容..." \
  -F "forceReAlign=true"
```

## 🎨 技术架构

### 核心组件

```
┌─────────────────────────────────────┐
│        Controller 层                │
│  ┌──────────────────────────────┐  │
│  │ AudioGeneratorController     │  │
│  │ VideoGeneratorController     │  │
│  └──────────────────────────────┘  │
└─────────────────────────────────────┘
                ↓
┌─────────────────────────────────────┐
│        Service 层                   │
│  ┌──────────────────────────────┐  │
│  │ AudioGeneratorService        │  │
│  │ SubtitleAlignmentService     │  │
│  │ VideoGeneratorService        │  │
│  └──────────────────────────────┘  │
└─────────────────────────────────────┘
                ↓
┌─────────────────────────────────────┐
│        底层服务                     │
│  ┌──────────────────────────────┐  │
│  │ DocumentTTSService  (TTS)    │  │
│  │ WhisperXService    (对齐)    │  │
│  │ FFmpegUtil         (视频)    │  │
│  └──────────────────────────────┘  │
└─────────────────────────────────────┘
```

### 字幕对齐策略

```
输入: MP3 + 原始字幕/文本
        ↓
   检测音频是否变化
        ↓
    ┌───┴───┐
    ↓       ↓
  未变化   变化
    ↓       ↓
 直接使用  WhisperX对齐
 原始字幕   重新生成
    ↓       ↓
    └───┬───┘
        ↓
   返回DialogSegment
```

## 📞 常见问题

### Q1: 字幕不同步怎么办？

**A**: 检查以下几点：
1. 是否使用了编辑后的MP3？设置`forceReAlign=true`
2. WhisperX服务是否正常运行？
3. 原始文本是否准确？

### Q2: 生成失败怎么办？

**A**: 查看错误信息：
1. `AUDIO_ERROR`: TTS服务问题
2. `VIDEO_ERROR`: FFmpeg问题
3. `SUBTITLE_ERROR`: WhisperX问题

### Q3: 如何提升生成速度？

**A**: 优化建议：
1. 使用缓存（相同文档不重复生成）
2. 使用GPU加速（FFmpeg、WhisperX）
3. 异步处理（返回taskId，轮询结果）

### Q4: 支持哪些音频格式？

**A**: 当前主要支持：
- MP3 ✅
- WAV ✅
- M4A ⚠️ (需要FFmpeg转换)
