## 🐛 常见问题排查

### 问题1：编译失败
```
错误：找不到符号 getAudioPathFromUrl

解决方案：
1. 检查VideoGeneratorServiceImpl.java是否正确添加了新方法
2. 刷新IDE项目（File → Reload Project）
3. 重新编译（mvn clean compile）
```

### 问题2：API限流错误
```
错误：TTS API返回429错误

原因分析：
- 10线程并发超过了账号QPS限制（默认QPS=10）

解决方案：
1. 检查火山引擎账号的QPS配额
2. 如果QPS<10，联系火山引擎提升配额
3. 临时方案：将线程池改回7（稍微降低并发）
```

### 问题3：文件路径错误
```
错误：音频文件不存在

原因分析：
- getAudioPathFromUrl路径解析错误

解决方案：
1. 检查outputDir配置是否正确
2. 检查audioUrl格式是否正确
3. 添加日志打印中间路径：
   log.info("audioUrl={}, audioPathStr={}", audioUrl, audioPathStr);
```
